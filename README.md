# SwitchBar

一个**完全离线、源码公开**的 macOS 菜单栏开关工具，功能参照 One Switch：把隐藏桌面、深色模式、保持亮屏、勿扰模式、夜览、连接 AirPods、关闭显示器、取色、纯文本粘贴这些常用功能集中到菜单栏的一个面板里，点一下就切换，也可以给每个功能设置全局快捷键。

常驻菜单栏时**很轻**：不轮询、不在后台刷新，面板和设置窗口关掉后立刻释放；CI 每次构建都会实测常驻内存和空闲 CPU，超标就失败（数据见下文「常驻资源占用」）。

界面参照 macOS 26 / 27 自带的「控制中心」：液态玻璃背景、单色图标，只有开启的开关才会亮起系统强调色，每个开关下面直接写着当前状态（开启、还剩 42 分钟、已连接……）。面板顶部可以一键切换专注 / 夜间**场景**，还有**专注计时**。在 macOS 13–15 上背景会自动换成毛玻璃。

## 为什么自己写一个

| | SwitchBar 的做法 |
|---|---|
| 源码 | **MIT 开源许可（OSI Approved）**，约 4600 行 Swift，可自行审查、修改和编译 |
| 网络 | **代码里没有任何网络请求**。`scripts/audit.sh` 会检查，CI 里如果发现网络代码会直接失败 |
| 依赖 | 零第三方依赖，只用苹果系统框架（`Package.swift` 里没有 dependencies） |
| 数据 | 设置只保存在本机 `~/Library/Preferences/local.switchbar.plist` |
| 权限 | 按需申请：只有用到对应功能时，系统才会弹窗询问 |
| 安装包 | Releases 里的安装包由 GitHub Actions 从这份源码自动构建，附 SHA-256 校验值；也可以自己编译 |

## 功能

点菜单栏图标（或按 **⌃⌥⌘S**）打开面板；右边带「›」的开关还有更多选项。点面板外面或按 Esc 关闭，不会抢走当前应用的焦点。

| 开关 | 说明 | 实现方式 | 需要的权限 |
|---|---|---|---|
| 隐藏桌面 | 一键隐藏 / 显示桌面上的所有图标 | `defaults write com.apple.finder CreateDesktop` + 重启访达 | 无 |
| 深色模式 | 切换深色 / 浅色外观 | AppleScript 控制「系统事件」 | 自动化（首次询问） |
| 保持亮屏 | 阻止屏幕自动休眠，可选 15 分钟 ~ 8 小时或一直保持 | IOKit 电源断言（和 `caffeinate -d` 相同） | 无 |
| 勿扰模式 | 开 / 关勿扰 | 系统「快捷指令」（需要一次性设置，见下文） | 无 |
| 夜览 | 开 / 关夜览 | CoreBrightness（系统设置自己用的框架） | 无 |
| 麦克风静音 | 静音当前输入设备 | CoreAudio 设备属性（不采集声音） | 无 |
| 蓝牙耳机 | 一键连接 / 断开选中的 AirPods 等耳机 | IOBluetooth | 蓝牙（首次询问） |
| 显示隐藏文件 | 访达里显示 / 隐藏以 `.` 开头的文件 | `defaults write com.apple.finder AppleShowAllFiles` | 无 |
| 显示扩展名 🆕 | 访达里显示所有文件的扩展名（.pdf、.zip……） | `defaults write -g AppleShowAllExtensions` | 无 |
| 隐藏程序坞 | 开 / 关程序坞自动隐藏 | AppleScript 控制「系统事件」 | 自动化（首次询问） |
| 隐藏菜单栏 | 开 / 关菜单栏自动隐藏，刘海屏上看视频更干净 | AppleScript 控制「系统事件」 | 自动化（首次询问） |

| 工具 | 说明 | 实现方式 | 需要的权限 |
|---|---|---|---|
| 锁定屏幕 | 立即锁屏（等同 ⌃⌘Q） | login 框架 `SACLockScreenImmediate` | 无 |
| 关闭显示器 🆕 | 立即关掉屏幕，电脑继续运行（下载、音乐不中断） | `pmset displaysleepnow` | 无 |
| 屏幕保护 | 立即启动屏幕保护程序 | 打开系统自带的 ScreenSaverEngine | 无 |
| 睡眠 🆕 | 让电脑立即睡眠 | `pmset sleepnow` | 无 |
| 清洁屏幕 | 全屏变黑 + 锁键盘 + 屏蔽触控板手势，按住按钮 2 秒解锁 | CGEventTap | 辅助功能 |
| 取色器 🆕 | 吸取屏幕上任意一点的颜色，自动复制 `#RRGGBB` 色值 | 系统自带的取色放大镜（NSColorSampler） | **无**（不需要屏幕录制） |
| 纯文本 🆕 | 去掉剪贴板里文字的字体、颜色、链接等格式，再粘贴就是纯文字；「›」里还能清空剪贴板 | NSPasteboard，只在你点的那一刻读写一次 | 无 |
| 声音设备 | 一键切换扬声器、AirPods、显示器音箱，以及麦克风 | CoreAudio | 无 |

> v2.0 删掉了用得少的「静音」「推出磁盘」「锁定键盘」「分辨率」「原彩显示」和「演示」场景：面板更简洁、程序更小；「辅助功能」权限现在只有清洁屏幕会用到。

### 专注计时

点面板顶部的「专注计时」开始倒计时（默认 25 分钟），菜单栏会显示剩余时间；默认会自动开启「专注」场景，时间到了播放提示音、弹出提醒，并恢复原来的设置。在按钮上点右键可以选 15 / 25 / 45 / 60 分钟，或者再加 5 分钟。

### 电量

MacBook 上，面板右上角会显示电池电量和充电状态。

在「设置 › 功能与快捷键」里可以：勾选要显示的开关、拖动调整顺序、为每个开关录制全局快捷键（例如 ⌃⌥D 切换深色模式）。用快捷键操作时屏幕下方会短暂显示提示。

## 常驻资源占用

SwitchBar 平时只是菜单栏上的一个图标：不轮询系统状态、不在后台刷新界面，面板、设置窗口、提示框关掉后立刻释放；启动时也不读取任何开关的状态，第一次打开面板时才读。

CI 每次构建都会启动编译好的 SwitchBar、让它空闲 60 秒，测量常驻内存和 CPU（`scripts/resource-test.sh`），常驻内存超过 20 MB 或者空闲 1 分钟用掉超过 0.1 秒 CPU 就直接失败。下面是 GitHub 的 macOS 虚拟机上的实测结果：

| | v1.3 | v2.0 |
|---|---|---|
| 常驻内存（macOS 26 / macOS 14） | 27.1 MB / 19.5 MB | **10.1 MB / 7.6 MB** |
| 空闲 1 分钟用掉的 CPU 时间 | 1.07 秒 / 0.76 秒 | **0.013 秒 / 0.001 秒** |
| 空闲 1 分钟内被唤醒的次数 | 124 次 / 483 次 | **3 次 / 0 次** |

v1.3 一启动就把面板界面建好、一直留在内存里（面板里有每秒刷新一次的倒计时）；v2.0 改成打开面板时才创建、关掉就释放，所以空闲时几乎不占 CPU，也更省电。在你自己的 Mac 上，可以打开「活动监视器」搜索 SwitchBar，看「内存」和「% CPU」两列。

## 安装

需要 macOS 13 Ventura 或更新版本（推荐 macOS 26 及以上，可以看到液态玻璃效果）。

### 方法一：从 Releases 下载（推荐，最简单）

1. 打开 [Releases 页面](https://github.com/eric-prog998/mac-SwitchBar/releases/latest)，下载 `SwitchBar-vX.Y.Z.zip`。
2. 双击解压，把 **SwitchBar.app** 拖进「应用程序」文件夹。
3. SwitchBar 没有经过苹果公证（需要付费开发者账号），系统默认会拦下从网上下载的应用。打开「终端」执行一次：

   ```bash
   xattr -dr com.apple.quarantine /Applications/SwitchBar.app
   ```

   或者：先双击打开一次，被拦下后到「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」。
4. 打开 SwitchBar，菜单栏右上角会出现一个开关图标。
5. 想开机自动启动：面板右上角「…」› 设置… › 通用 › 勾选「登录时自动启动」。

**校验安装包（可选）**：每个版本的 Releases 页面都附有 SHA-256，和下面命令的输出一致就说明文件没被篡改：

```bash
shasum -a 256 ~/Downloads/SwitchBar-v2.0.0.zip
```

**升级**：退出旧版（面板右上角「…」› 退出 SwitchBar），下载新版替换掉「应用程序」里的旧版，再执行一次上面的 `xattr` 命令。每个版本的签名不同，「清洁屏幕」用到的「辅助功能」权限需要在系统设置里删掉 SwitchBar 后重新添加。

### 方法二：自己编译（大约 1 分钟）

1. 安装编译工具（已经装了 Xcode 可以跳过）：

   ```bash
   xcode-select --install
   ```

2. 下载源码并安装：

   ```bash
   git clone https://github.com/eric-prog998/mac-SwitchBar.git
   cd mac-SwitchBar
   make install
   ```

   仓库是公开的，可以直接克隆；也可以用 GitHub Desktop 克隆，然后在终端里 `cd` 到克隆下来的文件夹执行 `make install`。

   脚本会编译出 `dist/SwitchBar.app`，复制到「应用程序」文件夹并启动。用 Xcode 26 或更新版本编译才会包含液态玻璃效果。

以后更新代码后，再执行一次 `make install` 即可。

#### 推荐：创建本地签名证书（只需一次）

macOS 用代码签名来识别「是不是同一个应用」。默认的临时签名每次编译都会变，导致**每次重新编译后都要重新授予「辅助功能」权限**。创建一个只存在于你本机的自签名证书就能避免：

1. 打开「钥匙串访问」→ 菜单栏「钥匙串访问」›「证书助理」›「创建证书…」
2. 名称填 `SwitchBar Local`，身份类型选「自签名根证书」，证书类型选「**代码签名**」，点「创建」
3. 重新执行 `make install`，脚本会自动使用这个证书（第一次可能会询问是否允许 codesign 使用钥匙串，点「始终允许」）

这个证书只在你的电脑上，不需要 Apple 开发者账号。

### 发布新版本

GitHub Actions 会在 macOS 上自动构建、打包，并把 `SwitchBar-vX.Y.Z.zip` 和校验值上传到 Releases（流程见 `.github/workflows/release.yml`）。两种触发方式任选一种：

- 推送一个 `v` 开头的标签：

  ```bash
  git tag v1.0.1
  git push origin v1.0.1
  ```

- 或者在 GitHub 网页上打开仓库的 **Actions › Release › Run workflow**，填入版本号（例如 `1.0.1`），会自动创建 `v1.0.1` 标签并发布。

## 14 英寸 MacBook Pro 小贴士

- **菜单栏图标被刘海挡住了？** 菜单栏图标多的时候，新加入的图标会被挤到刘海后面。可以：
  - 按 **⌃⌥⌘S** 直接打开面板（在 设置 › 功能与快捷键 里可以改）；
  - 按住 ⌘ 把 SwitchBar 图标拖到靠右的位置，SwitchBar 会记住这个位置；
  - macOS 26 及以上可以在「系统设置 › 菜单栏」里隐藏不常用的图标。
- **面板大小**：面板宽 356 点、高不到 620 点，在 14 英寸屏幕所有缩放档位（包括「更大字体」1024 × 665）下都能完整显示；如果把开关全打开还嫌挤，可以在设置里隐藏不常用的开关。
- **关闭显示器**：离开一会儿又不想锁屏、不想让电脑睡眠（比如下载、放音乐）时很好用；想顺便锁屏，就在 系统设置 › 锁定屏幕 里把「显示器关闭后需要密码」设为「立即」。
- **夜览**：内建屏幕都支持。

## 勿扰模式的一次性设置

macOS 没有公开接口可以切换勿扰模式，SwitchBar 借助系统自带的「快捷指令」完成（不需要额外权限）：

1. 打开「快捷指令」App，新建快捷指令，添加操作「**设定专注模式**」，设为「打开 勿扰模式」，命名为 `开启勿扰`
2. 再新建一个，设为「关闭 勿扰模式」，命名为 `关闭勿扰`
3. 在 SwitchBar 设置 › 勿扰模式 里点「检查」，看到 ✅ 就完成了（名字也可以在这里改）

## 安全

SwitchBar 要用到一些系统权限，所以安全是第一位的。下面是它的防护设计，以及你自己怎么验证。

### 它能不能被网络攻击、被远程控制？

不能，原因是它**根本没有能被连上的地方**：

| 攻击途径 | SwitchBar 的情况 |
|---|---|
| 通过网络连进来 | 程序里没有任何联网代码，不监听任何端口。CI 每次构建都会同时检查**源码**（`scripts/audit.sh`）和**编译出来的程序**（`scripts/audit-binary.sh`，用 `nm` 查它调用的全部系统函数），出现 socket、URLSession、Network 框架等任何联网函数都会直接失败 |
| 其他程序给它发指令 | 没有网址协议（URL Scheme）、没有 AppleScript 接口、没有后台服务（XPC）。别的程序没有办法让 SwitchBar 执行任何操作 |
| 恶意软件借用它的权限 | 以**强化运行时**（Hardened Runtime）签名：系统会阻止其他程序向 SwitchBar 注入代码或用调试器附加，也就没法借 SwitchBar 已经拿到的「辅助功能」等权限做坏事 |
| 执行外部命令被篡改 | 只调用 4 个 macOS 自带命令（`defaults`、`killall`、`pmset`、`shortcuts`），参数都是写死的，不经过 shell，不存在命令注入 |
| 偷看你打字、看屏幕、看剪贴板 | 全局快捷键用的是只能收到「自己注册的组合键」的系统接口；清洁屏幕时按键直接丢弃，不保存任何内容；「纯文本」只在你点的那一刻读写一次剪贴板；「取色器」用系统的取色放大镜，SwitchBar 自己看不到屏幕 |
| 安装包被调包 | Releases 的安装包由 GitHub Actions 从源码自动构建，附 SHA-256；构建用到的第三方 Action 固定在具体的提交上；也可以完全不用安装包，自己编译 |

### 它到底有哪些权限？

打开 **设置 › 安全与权限**，「权限体检」会实时显示 SwitchBar 在你电脑上拥有的权限（只查询，不会弹窗申请）：

<img src="docs/screenshots/settings-security.png" width="640" alt="设置：安全与权限">

> 上面的截图是在 CI 虚拟机上从「终端」启动调试版截的：终端本身拥有屏幕录制等权限，从终端启动的程序会继承，所以显示「已允许，建议关闭」。正常从「应用程序」打开时，显示的是 SwitchBar 自己的权限。

| 权限 | 用在哪里 | 不用这些功能时 |
|---|---|---|
| 辅助功能 | 清洁屏幕（擦屏幕时暂时拦截按键和手势） | 隐藏这个开关，并在系统设置里关掉 |
| 自动化 › 系统事件 | 深色模式、隐藏程序坞、隐藏菜单栏 | 同上 |
| 蓝牙 | 蓝牙耳机 | 同上 |
| **屏幕录制** | **不需要**，代码里没有任何录屏功能（取色器也不需要） | 如果体检显示「已允许」，点「去关闭」 |
| **输入监控** | **不需要** | 同上 |
| 完全磁盘访问、麦克风、摄像头、定位、通讯录、照片 | 从不申请 | — |

Entitlements（程序声明的特殊权利）只有一项：`com.apple.security.automation.apple-events`，用来向「系统事件」发送切换深色模式等指令，见 `Resources/SwitchBar.entitlements`。

### 自己动手验证

```bash
# 1. 确认 SwitchBar 没有任何网络连接（没有任何输出就对了）
lsof -i -a -p $(pgrep -x SwitchBar)

# 2. 检查已安装的程序：联网函数、链接的框架、强化运行时、entitlements
./scripts/audit-binary.sh /Applications/SwitchBar.app

# 3. 检查源码：网络代码、会执行的外部命令、私有框架、第三方依赖
make audit

# 4. 一键撤销 SwitchBar 获得的所有系统权限（下次用到时会重新询问）
tccutil reset All local.switchbar
```

`make audit` 会列出：

1. 网络相关代码（应该为空）
2. 会执行的外部命令：只有 `/usr/bin/defaults`、`killall`、`pmset`、`shortcuts`，全部是 macOS 自带
3. 用到的非公开系统框架：`CoreBrightness`（夜览）、`login`（锁屏）
4. 第三方依赖（应该为空）

## 常见问题

**清洁屏幕提示「无法拦截键盘」？** 重新安装或重新编译后旧的授权失效了。到「辅助功能」里选中 SwitchBar 点「−」删除，再重新打开清洁屏幕，按提示重新授权。自己编译的话，按上面的方法创建本地签名证书可以一劳永逸。

**深色模式 / 隐藏程序坞 / 隐藏菜单栏没反应？** 第一次使用时系统会问「是否允许 SwitchBar 控制系统事件」，需要点「好」。如果之前点了「不允许」，到「自动化」里重新打开。

**锁定屏幕后没有要求密码？** 如果系统将来移除了锁屏接口，SwitchBar 会改为让显示器立即关闭，此时需要在 系统设置 › 锁定屏幕 里把「显示器关闭后需要密码」设为「立即」。

**清洁屏幕时电脑睡着了怎么办？** 合上屏幕、电脑睡眠或锁屏时，SwitchBar 会自动解除锁定，回来后可以正常输入密码。

**取色器怎么用？** 点「取色器」（或按 ⌃⌥P）后会出现系统的放大镜，移到想要的位置点一下，色值（例如 `#0A84FF`）就复制好了，屏幕下方会显示取到的颜色；按 Esc 取消。

**纯文本为什么不直接帮我粘贴？** 自动粘贴需要模拟按键，要额外的权限，所以 SwitchBar 只负责把剪贴板里的格式去掉，粘贴还是你自己按 ⌘V。密码管理器标记为「敏感」的内容，转换后仍然保留这个标记。

**勿扰模式开关状态不准？** 如果系统允许读取专注模式状态，SwitchBar 显示的就是真实状态；否则显示的是上一次通过 SwitchBar 操作的结果。点开关右边的「›」可以直接选「开启」或「关闭」。
